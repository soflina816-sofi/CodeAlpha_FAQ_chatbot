# CodeAlpha FAQ Chatbot

An NLP-based FAQ chatbot developed as part of the CodeAlpha AI Internship.

## Technologies Used
- Python
- Gradio
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity

## How It Works
The chatbot compares a user's question with predefined FAQs and returns the most relevant answer.

## How to Run
Install the dependencies:

pip install -r requirements.txt

Run the application:

python app.py
